# Agentic Workflow Visualizer

Combine agent prompt routing with automatic diagram generation to produce visual workflows from natural language prompts.

Built by Swings AI from its own skill tools, one milestone per session.

## Milestones

1. M1: Route and Spec: Route an input prompt and generate a corresponding graph specification.
2. M2: Complete Workflow Diagram Generator: Generate Mermaid and PlantUML markup from the routed agent prompt.
