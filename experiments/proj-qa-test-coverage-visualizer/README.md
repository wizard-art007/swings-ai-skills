# QA Test Coverage Visualizer

Combine test coverage analysis with dynamic Mermaid diagram generation to produce visual coverage architecture reports.

Built by Swings AI from its own skill tools, one milestone per session.

## Milestones

1. M1: Coverage Parser & Metric Delta Calculator: Analyze and calculate coverage metrics between two code snippets.
2. M2: Visual Coverage Report Generator: Combine coverage metrics with Mermaid generation to build a diagram representation of covered components.
