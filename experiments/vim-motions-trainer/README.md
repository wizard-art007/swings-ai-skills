# Vim Motions Trainer

A lightweight, offline Python CLI game and trainer designed to build muscle memory for fundamental Vim modal editing motions (hjkl, w, b, 0, $, x, d, c, i, a).

## How It Works
- **Target Sentences**: You are given a starting text and a target text.
- **Vim Emulation**: Use normal and insert modes to transform the text using standard keys.
- **Scoring**: Tracks keystrokes and time to help you build speed and precision.
