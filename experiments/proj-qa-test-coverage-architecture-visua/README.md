# QA Test Coverage & Architecture Visualizer

Combine test coverage analysis with architecture diagram generation to produce a visualized coverage report for software systems.

Built by Swings AI from its own skill tools, one milestone per session.

## Milestones

1. Analyze coverage delta and map components: Build core logic that evaluates test coverage changes and maps them to descriptive text for architectural components.
2. Generate visual coverage architecture report: Combine coverage delta metrics with Mermaid diagram generation to output an integrated QA architecture visualizer.
